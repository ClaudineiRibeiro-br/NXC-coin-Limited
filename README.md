## 🔒 Fixed Supply — Official Statement

The total supply of **1,000,000,000,000 NXC (one trillion)** was minted in full at the moment of deployment and represents the absolute and permanent limit of this currency.

**There is no mint function in this contract.** No entity — including the creator — has the authorization or technical capability to create new NXC tokens beyond this initial supply.

Any token that identifies itself as NXC with a contract address different from this one is fraudulent and has no relation to the NX Wallet project.
